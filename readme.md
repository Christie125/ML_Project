This project us called Exam Score Predictor. It allows users to input data about themselves such as their age, sleep hours, time spent studying for the exam etc. and recieve an AI prediction of their exam score.

I created this project to practise the skills and knowledge on linear regressions models I had learnt in Google's Machine Learning Crash Course. With coding projects, I'm a very hands-on learner, so I hoped that doing something practical would help to solidify what I had learnt.

I made this by firstly creating a linear regression model using SciKit-Learn. This involved finding data on Kaggle, cleaning the aforementioned data, and creating, training, and refining a linear regression model. Luckily, this was not too difficult, although refining proved to be a challenge and I had to research ways to make my model's MSE go down. I was able to lower it to around 8, which is OK -- while not ideal, I recognise the limits of both myself, the tools available to me, and my data, and will endevour to enchance thiese

I learnt lots of things while creating this project, including but not limited to:

How to make a timer in JS
How to use Date in JS
How to use and update and delete from local storage
How to initialise a Chrome extension
How manifest.json works
How to publish a Chrome extension
It was a lot easier than I initially expected, but I nevertheless struggled with debugging, especially the UI elements and the setTimer function. However, I was able to use resources online to overcome these challenges and get my project working. I was also really lucky that Athena has a Chrome Developer License as a prize, so I didn't have to pay! This made deployment a lot quicker.
