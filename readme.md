This project us called Exam Score Predictor. It allows users to input data about themselves such as their age, sleep hours, time spent studying for the exam etc. and recieve an AI prediction of their exam score.

I created this project to practise the skills and knowledge on linear regressions models I had learnt in Google's Machine Learning Crash Course. With coding projects, I'm a very hands-on learner, so I hoped that doing something practical would help to solidify what I had learnt.

I made this by firstly creating a linear regression model using SciKit-Learn. This involved finding data on Kaggle, cleaning the aforementioned data, and creating, training, and refining a linear regression model. Luckily, this was not too difficult, although refining proved to be a challenge and I had to research ways to make my model's MSE go down. I was able to lower it to around 8, which is OK -- while not ideal, I recognise the limits of both myself, the tools available to me, and my data, and will endeavour to enchance these aspects in the future.
Then, I created a simple Flask and JS backend, which was a lot simpler than I thought. I was able to revise my Flask knowledge and revise using JS to send data to the backend and receive a response.
Then came the fun part -- the UI! I wanted to make it as user-friendly and visually appealing as possible, so I used my creativity and design skills to create a simple yet effective interface with a light academia theme, which I think suits the project well. I used HTML and CSS to create the layout and styling.
I also made sure to test the UI on different devices and browsers to ensure it was responsive and accessible to all users, and I went through the w3schools accessibility checklist to make sure I had done everything I could to make it accessible.
I also went through the OWASP security checklist to make sure I had done everything I could to make it secure, and I implemented measures such as input validation  prevent common security vulnerabilities.I don't want my website to break!
Lastly, I added a section with tips to help users actually use the insights that they gained from the AI and deployed my app using PythonAnywhere.

I learnt and revised lots of things while creating this project, including but not limited to:
-> How to create and refine a linear regression model using SciKit-Learn
-> How to find and clean data for machine learning projects
-> How to save a model using Pickle and load it in a backend
-> How to create a simple Flask and JS backend
-> How to create a simple yet effective UI using HTML and CSS
-> How to make a website responsive and accessible
-> How to make a website secure
-> How to deploy an app using PythonAnywhere

The project is not perfect, and there are many ways I could improve it, such as by using a more complex model to lower the MSE, finding better data, and adding more features. 

This project had a big learning curve, due to the fact that it was my first machine learning endeavour, as previously mentioned. However, I learnt to use available resources, both online and otherwise, to efficiently and effectively to find answers to my questions and learn how to do new things. Some of the most prominent challenges included not knowing how to use new technologies and getting my model to be more accurate.

However, I'm proud of what I've created, especially as it was my first time creating a machine learning project, and I'm excited to continue learning and improving my skills in the future.
